Use Steam BO3 Mod Tools. Create an egg_live mod, copy mod/scripts, zone_source and sound into it. Copy mod/sound_assets/egg_live into Tools/sound_assets and mod/sound/aliases/egg_live.csv into Tools/share/raw/sound/aliases. Link core_mod then zm_mod with linker_modtools.exe -language english -fs_game egg_live -modsource <zone>. Use the official launcher for Workshop upload. Do not include user settings or logs. For the source companion run npm ci --ignore-scripts in companion; use Node 22+ and Python 3.13+ on Windows. The Windows release contains the runtimes. The player release enables real LIVE but starts disconnected. Synthetic test endpoints require EGG_LIVE_TEST_TOOLS=1 explicitly for developer checks. See launcher/BUILD.txt for the single Windows launcher.
